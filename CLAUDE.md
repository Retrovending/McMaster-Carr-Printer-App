# Repository guidance

Chrome MV3 product-label extension. Plain browser JS, no framework or build step. Keep injected supplier extractors self-contained. Rendering lives in extension/label.js; popup editing and local layout/size libraries live in extension/popup.js. extension/printing.js only transports rendered jobs to Chrome's print dialog; do not add direct/default printer selection. Keep physical dimensions, rotation, preview and print geometry consistent. Built-in starting layouts are removable/editable library entries seeded once. Existing local user layouts must survive updates. Named layouts store normalized element geometry, enabled flags and rotation; custom sizes store inches. Export supports promoting user-approved layouts into future defaults. Do not promote experimental layouts without the user's selection.

Run npm test after meaningful rendering or workflow changes. After layout changes run npm run layouts and visually inspect docs/30336-layouts.png. Keep QR readability tests. Bump version in manifest.json and package.json (and package-lock metadata). Preserve upstream MIT licensing.
